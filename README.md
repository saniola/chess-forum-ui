# chess-forum-ui

Static mock-up of a chess forum interface built with Jade templates, SCSS, and Gulp.

## Features

- Two-column forum layout with thread list and sidebar
- Compiled HTML output from Jade templates
- Custom SCSS styling with vendor CSS bundle

## Stack

- Jade for HTML templating
- SCSS for styling
- Gulp for build automation
- FontAwesome icons

## Project structure

```
app/
  jade/           # Jade templates (index.jade, includes/)
  scss/           # SCSS stylesheets
  js/             # JavaScript sources
  vendor/         # vendor assets
dist/             # compiled HTML, CSS, JS output
```

## Build

Requires Node.js and Gulp installed globally.

```bash
npm install
gulp
```
